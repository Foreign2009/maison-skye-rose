**Status:** Complete
**Program:** EP50-P1 — Experience Release 5.0 / Explainable MiniCart Recommendations

**Goal:**
Preserve recommendation reasons through `CartRecommendationStrategy.resolveComplementary()` and surface them in MiniCart's "Complete Your Collection" section. Reasons were already generated by the engine but discarded during the `DisplayFragrance` mapping step.

**Acceptance Criteria:**
- [x] `CartRecommendationStrategy` preserves `reasons[0].description` as `recReason` on collection items
- [x] MiniCart "Complete Your Collection" renders `recReason` beneath each fragrance title
- [x] Falls back to `fragrance.profile` when `recReason` is null
- [x] RecommendationEngine, RecommendationReasonBuilder, LearningEngine unchanged
- [x] Commerce behaviour unchanged
- [x] Build passes — TypeScript clean, 0 warnings, 247 routes

**Why This Task:**
`resolveComplementary()` mapped `Recommendation → DisplayFragrance` via `slugToDisplay()`, discarding `Recommendation.reasons`. Reasons were fully generated and ranked by `RecommendationReasonBuilder` but never reached the render layer. A `CartCollectionItem` type extending `DisplayFragrance` with `recReason` threads them through without modifying the engine.
